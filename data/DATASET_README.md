# G1 闪身步 / 狗熊哆嗦毛 模仿学习数据集（v0，2026-10-18）

从 B 站单人舞蹈视频重建、重定向到 Unitree G1（29 自由度）的参考动作，附视觉大模型（VLM）标注。
用于 mjlab / BeyondMimic 式 RL 动作跟踪训练。数据在 WSL：`~/projects/dance/dataset/`，清单 `manifest.json`。

## 规模

| | 片段 | 时长 |
|---|---|---|
| 闪身步 | 11（4 位舞者：北舞赵铁春、TonyFu、健身房、卫衣男、街头 5 段） | 36.0 s |
| 狗熊哆嗦毛 | 3（北舞明文军 2 段、北舞白衣男舞者 1 段） | 13.3 s |
| 闪身步（拉丁版） | 1 | 12.5 s |
| **合计（不重复）** | **15** | **61.8 s** |
| 重复上传（只用于一致性检验） | 1：`bda2_gxdsm_wide` = `bda_ming_gxdsm_a` 的另一份上传 | 3.5 s |

漏斗：130 个检索结果 → 97 个下载成功（其余为 503、超长或下载失败）→ 全部由 VLM 筛选 →
约 9 个视频含可用的单人、全身、固定机位示范 → 切出 17 个片段（含 1 段重复）。
大部分检索结果不可用：动画、游戏、新闻、多人群舞、AI 二创、拼接剪辑。

## 流程

1. **检索**：yt-dlp 在 B 站按 8 个关键词检索，得到 130 个候选视频；下载时长不超过 5 分钟的视频（不登录时多为 360p）。
2. **筛选（VLM）**：每个视频均匀抽 8 帧拼成总览图，判断：是不是真人、是否单人全身、机位是否固定、是不是闪身步、是否重复转载。
   通过的视频再按每 0.25 秒一帧细看，确定片段起止，同时避开镜头切换和近景特写。
3. **3D 人体**：GVHMR（固定机位模式），输入统一转为 30fps。输出世界坐标系下的 SMPL-X 参数。
4. **重定向**：GMR（`smplx_to_g1`，mink IK）把人体动作映射到 G1 的 29 个关节。
5. **标注（VLM + 2D 校验）**：把 GVHMR 跟踪到的人物框裁出来，每 2–4 帧取一张拼图，逐段判断动作阶段，以及左右脚是否着地。
   同时用 ViTPose 的 2D 脚踝速度做交叉校验（固定机位时，踩地的脚在图像里不动）。
6. **触地修正**：重建结果整体悬空 4–9 cm，并随时间漂移。在标为"踩地"的帧上，让踩地脚的最低点贴住地面，
   逐帧求出根节点的高度偏移，再插值和平滑（`ground_fix.py`）。
7. **锁脚**：在每段"踩地"区间里，把脚的水平位置钉在该区间的中位数上；摆动帧的修正量线性插值。
   然后用 mink 做逐帧 IK：脚去目标位置，骨盆、躯干、手腕尽量保持原样（`foot_lock.py`）。
8. **跳切检查**：B 站教学视频常把几段示范拼接在一起。用相邻帧像素差的突变检测切点（`detect_cuts.py`），
   含切点的片段拆开后再处理，否则 GVHMR 会让根节点在切点处瞬移。
9. **转换**：`unitree_rl_mjlab/scripts/csv_to_npz.py`，从 30fps 插值到 50fps，正运动学算出全部刚体的位姿和速度。

## 每个片段的文件

| 文件 | 内容 |
|---|---|
| `g1_30fps.csv` | 根节点位置(3) + 根节点四元数 xyzw(4) + 29 个关节角，30fps，未修正 |
| `g1_50fps.npz` | mjlab 跟踪格式：`joint_pos/joint_vel`(T,29)，`body_pos_w/body_quat_w(wxyz)/body_lin_vel_w/body_ang_vel_w`(T,30,·) |
| `g1_ground_vlm_*.{csv,npz}` | 用 VLM 触地标注修正高度后的版本 |
| `g1_ground_heuristic_*.{csv,npz}` | 用"脚速 < 0.25 m/s"启发式触地修正高度的版本（消融对照） |
| `g1_lock_vlm_*.{csv,npz}` | 高度修正 + 用 VLM 触地标注锁脚（**推荐用于训练**） |
| `g1_lock_heuristic_*.{csv,npz}` | 高度修正 + 用启发式触地锁脚（消融对照） |
| `smplx_world.npz` | GVHMR 世界坐标 SMPL-X：`global_orient, body_pose, transl, betas`，30fps |
| `annotation.json` | VLM 标注：逐帧 `phase`、`contact_L/R`（1 踩地 / 0 离地 / -1 不确定）、`rsi_weight`、事件列表、备注 |
| `labels_50fps.npz` | 同一套标签按 50fps 时间轴重采样（最近帧），可直接给 RSI 采样用 |
| `metrics.json` | 重定向质检：脚滑、关节超限、骨盆高度、估计身高 |

左右一律指**舞者本人**的左右（舞者面对镜头时，画面左侧是他的右边）。

## 阶段标签

`ready` 预备 · `stand` 站定 · `prep` 起势（手臂外摆、重心预压） · `flash` 闪（重心横移、迈步或弹步） · `hold` 定 ·
`recover` 收（一只脚离地收回） · `settle` 落稳 · `shake` 抖（狗熊哆嗦毛）。

`rsi_weight` 是给阶段感知 RSI 用的先验，按阶段赋权后归一化：
flash / recover 3.0，hold 2.0，shake 2.5，settle 1.5，prep 1.0，stand / ready 0.3。

## 观察到的现象（逐片段标注时记录）

- **两种闪身步风格**：赵铁春（北舞教材）先双脚同时弹起或滑动换重心，再收回一只脚；
  TonyFu 等翻跳者是"一脚迈出、另一脚跟收"的顺序迈步，两脚不会同时离地。
- **单目重建整体悬空**：站立帧的 G1 脚踝高度应约为 0.035 m，重建结果是 0.075–0.13 m，而且随时间漂移。
  只看高度阈值的触地判断因此失效，只看速度的判断较可靠。
- 运动模糊集中在闪的那 4–7 帧，这些帧的触地标为"不确定"。
- **高度修正**：加上"不许穿地"的约束后，VLM 标注和速度启发式的效果几乎一样
  （踩地脚平均离地：北舞 0.40 对 0.43 cm，TonyFu 0.38 对 0.40 cm，健身房 0.80 对 0.82 cm）。
  这一步主要靠"最低的脚贴地"，VLM 标注的增益很小。
- **锁脚**：这一步 VLM 标注明显更好。15 个片段（1585 帧；含 1 段重复上传，不含拉丁版）按帧加权：
  踩地脚平均水平速度 0.263 → **0.047**（VLM 标注锁脚）对 0.241（启发式锁脚），单位 m/s；
  踩地脚离地高度 3.8 → 0.6 cm。逐片段数字见 `results/foot_lock_summary.md`。
  狗熊哆嗦毛锁脚后仍有约 0.10 m/s 的残余打滑（闪身步约 0.03）：高抬腿加快速节奏，IK 在锁脚和保持原姿态之间有冲突。
  启发式和 VLM 的触地判定，逐帧一致率平均只有 0.74。

  每个片段只做了一次，**样本太少**。原因：启发式按"脚速低于阈值"判定踩地，正在打滑的脚速度高，
  会被判成离地，因此不会被锁住；VLM 看的是画面，与重建出的速度无关。
  注意：这里用 VLM 标注做评估，存在自我验证成分。独立的检验要看 RL 训练时哪个版本跟踪得更好、摔得更少。

- **同源一致性**：同一次表演的两份上传（960×720 与 768×576），各自独立重建和标注，结果接近：
  修正前打滑 0.428 对 0.397，锁脚后 0.102 对 0.114 m/s；离地高度 4.2→0.6 对 4.8→0.5 cm。

## 局限

- 原始视频多为 360p 竖屏；每个片段只有一次标注，没有第二个人复核。
- 北舞明文军那段视频，狗熊哆嗦毛最"抖"的部分是近景特写，看不到脚，没有收录；
  后来找到的北舞鼓子秧歌教材里，有一段 7.7 秒的全身完整示范（`bda2_gxdsm_full`）可以弥补。
- 拉丁版连续走位、腿部交叉，逐帧触地判断不可靠，开头之后全部标为"不确定"。
  这段不参与触地对比，也没有生成启发式锁脚版本。
- 街头 5 段每段只有 1–2.5 秒，是从剪辑合集里按切点拆出来的。
- 原始视频版权属于原作者，只用于个人研究，不对外发布；可以公开的只有重定向后的机器人动作和标注。
