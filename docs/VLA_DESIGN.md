# 看人跳舞、跟着跳的 G1：设计草案（2026-10-18）

目标：机器人站在人对面，用头部相机看人跳"闪身步"或"狗熊哆嗦毛"，用同一个模型（一个大脑）识别舞种和节拍，
同步跳出对应动作。要求对没见过的舞者、服装、背景有一定泛化能力。

## 相关工作与定位

| 工作 | 做法 | 区别 |
|---|---|---|
| HumanPlus（Stanford 2024）https://humanoid-ai.github.io/ | RGB 估人体姿态 → 重定向 → 底层策略逐帧照抄（shadowing） | 照抄单帧姿态：有延迟、继承估计噪声、不理解在跳什么 |
| ZeroWBC（2026.3）https://arxiv.org/abs/2603.09170 | VLM 从文本和第一人称视频预测未来人体动作 → 重定向 → 通用跟踪器 | 第一人称（自己的视角），不是看着对面的人 |
| TANGO（2026.9）https://huggingface.co/papers/2609.09158.md | VLA 直接输出 29 维关节动作，仿真里由 RL 跟踪器提供监督 | 任务是导航；"RL 专家监督 VLA"的思路相同 |

定位：**第三人称看伙伴 → 认出技能和节拍 → 执行自己学过、物理上可行的技能，并保持同步**（技能级跟随，而不是逐帧照抄）。
以上只基于两次检索，写进论文或简历前需要系统查新。

## 架构（一个网络，两个频率）

- 高层 VLA，10 Hz：冻结视觉编码器 + 时序 Transformer（约 1 s 窗口），输入头部相机画面和可选语言指令。
  输出动作潜变量或未来 0.5 s 的参考姿态；辅助头预测舞种、阶段、左右脚触地、节奏。
- 底层通用跟踪器，50 Hz：一个 RL 策略学会全部片段，负责平衡和触地，输出 29 维关节目标。

## 数据引擎（用训好的策略批量生成数据）

**修订（2026-10-18）**：只用渲染的 SMPL-X 虚拟人（无头发、无衣褶、材质失真）训练像素模型，
大概率迁移不到真人视频（视觉 sim2real 差距，且我们的数据量小）。主线改为**关键点中间表示**：

1. 每段动作训一个 RL 跟踪专家，再蒸馏成通用跟踪器。
2. 感知输入 = 人体关键点序列：由 ViTPose / GVHMR 从画面中提取，这两个模型在真实图像上训练，本身能处理真人画面。
3. 训练数据直接来自**真实视频**：每段已有 `vitpose.pt`（真实 2D 关键点），配同一时刻的专家动作 → 真实来源的成对数据。
4. 视角增强：用 GVHMR 的 3D 人体从随机相机位姿投影出 2D 关键点，加抖动、丢点、遮挡、时间伸缩。
5. 先行为克隆，再 DAgger 闭环纠错。
6. 渲染虚拟人降为可选补充（例如用于像素版 VLA 的预训练），不作为主数据来源。

像素版 VLA（之后）：冻结的真实图像预训练编码器（DINOv2 / SigLIP）+ 真实视频帧配专家动作；
约 1860 帧，只能作为补充。

## 先做的验证实验

用 6 位闪身步舞者的视频训练，留出 2 位；把留出视频的关键点喂给学生模型，
看仿真里的 G1 能否识别舞种并同拍跳出 → 直接回答"能不能看真人视频跳"。
真机头部相机（安装高度、视场、运动模糊不同）在没有硬件前无法验证。

## 创新点

1. **技能级跟随**（核心）：对比 HumanPlus 式逐帧照抄基线，指标是同步误差、摔倒率、遮挡和噪声下的鲁棒性。
2. **预判抵消延迟**：预测未来 0.5 s 的动作，同拍执行；用 VLM 标注的阶段边界衡量同拍程度。
3. **VLM 标注作辅助监督**：舞种、阶段、触地作为辅助任务，消融它们对泛化的贡献。
4. **泛化评测**：留出 2 位闪身步舞者；把真实 B 站视频投到仿真中的"屏幕"上，测从渲染画面到真实画面的差距。
5. **镜像跟随**：利用按舞者本人左右记录的标注做左右镜像增强，语言指令切换"镜像跟随 / 照着跳"。

## 风险

- 只有 2 种舞、十几段片段：泛化只能做到"没见过的舞者和画面"，做不到"没见过的舞种"（需要引入 AMASS 等）。
- 同步怎么评价（身高差、节奏差）需要先定义清楚。
- 8 GB 显存：像素版 VLA 要用小编码器和离线特征缓存。
